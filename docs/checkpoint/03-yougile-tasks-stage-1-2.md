Ниже — готовые карточки (контекст / сделать / готово / не входит).

## Как работает Excel

1. В комиссии **«Скачать бланк Excel»** — колонки: `last_name`, `first_name`, `middle_name`, `birth_date`, `city`, `group_name`, `start_number`, `rfid` (+ пример строк).
2. Организатор заполняет файл.
3. **«Загрузить Excel»**: заголовки = бланк → превью → импорт; иначе → маппинг колонок → превью → импорт.
4. Непустой `group_name` создаёт группу, если её ещё нет.
5. `start_number` уникален в рамках события.

- `mass_start_time`: общий старт (кнопка Старт = t0); каждое валидное пересечение = финиш участника; места по возрастанию времени от t0.
- `qualification_best`: лучшее время между двумя пересечениями или от якоря — **упрощение для MVP:** первое пересечение = старт участника (якорь), второе = финиш попытки; место по лучшему времени попытки; можно одну попытку на пилот.
- Сохранение результата локально (места, времена).
- Работа **без сети**.

**Критерий готовности:**
- Прогон на моке/тестовых метках без интернета → таблица мест на телефоне.
- После E2-08 пройден [чеклист мотокросса](./05-motocross-regression-checklist.md).

**Не входит:** эфир в Вокруг (этап 3), несколько антенн, LAN TV для новой дисциплины (можно позже).
