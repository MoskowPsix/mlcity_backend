## A. Вокруг (этап 1)

### A1. Админка (Moonshine)

| Экран                          | Кто      | Действия                                        |
| ------------------------------ | -------- | ----------------------------------------------- |
| Пользователь / доступ Чекпоинт | Менеджер | Включить/выключить **доступ Чекпоинт**          |
| Тот же или рядом               | Менеджер | Флаг **разрешить публикацию** (пилот до оплаты) |

### A2. Создание / редактирование мероприятия

- Как сейчас + чекбокс **«Использовать хронометраж Чекпоинт»**.
- Чекбокс виден **только** при доступе Чекпоинт.
- При включении: после сохранения — кнопки/ссылки **«Комиссия»** (и позже «Заявиться» — не в MVP).

### A3. Комиссия (своё событие с чекбоксом)

**Блок «Комиссия» — только владелец мероприятия**

0. Приглашение по почте. В списке почта, статус **«принял»** / **«не принял»**, кнопка **«Удалить»**.
    - Почта уже зарегистрирована — «принял», доступ к этой комиссии сразу, без флага «Доступ Checkpoint».
    - Почты нет — «не принял», пока не регистрация с этой почты.
    - Приглашённый блок не видит и сам никого не приглашает. Группы, участников и Excel этого события правит. Карточку и чекбокс — нет.

**Блок «Группы / классы»**

1. Таблица или список групп (название, число участников).
2. «Добавить группу», переименовать, удалить (если в группе 0 участников).

**Участники**

3. Таблица участников (ФИО, группа, номер, RFID, …).
4. **«Скачать бланк Excel»** — файл с фиксированными заголовками и 1–2 примерами (см. контракт §4.1).
5. **«Загрузить Excel»**:
    - заголовки как в бланке → сразу **превью** → подтверждение импорта;
    - иначе → **сопоставление колонок** → превью → импорт;
    - новые `group_name` из файла создают группы автоматически.
6. «Добавить участника» / редактирование / удаление.
7. Поля строки: фамилия, имя, отчество (опц.), дата рождения, город, **группа (выбор из списка)**, номер, RFID (опц.).
8. Ошибка при дубликате **стартового номера** в этом событии.

### A4. Профиль → Чекпоинт (заглушка MVP)

- Пункт меню есть и без флага. Без доступа: текст «Доступ выдаёт менеджер после комплекта», чужих списков нет.
- С доступом: статус доступа, статус «публикация разрешена/нет», список своих соревнований с датой и ссылкой в комиссию.
- Приглашённому в чужую комиссию в том же списке видно это событие с пометкой «вам открыли».
- Оплата — этап 5 (не рисовать checkout в MVP, достаточно заглушки).

### A5. Карточка события для зрителя (этап 3)

- Блок/вкладка **«Хронометраж»**: пусто → live → итоги.
- Не делать в этапе 1; заложить место в навигации карточки по желанию.

```text
Вокруг MVP (этап 1)
[Админка: доступ + publish flag]
        |
[Создать событие] --чекбокс--> [Комиссия: приглашения владельца + группы + участники]
                                  |
                    бланк Excel / загрузка / ручной ввод
        |
[Профиль → Чекпоинт: статус]
```

## B. Чекпоинт (этап 2)

### B0. Выбор спортивной дисциплины (`work-mode-modal`)

Единственный экран **выбора** дисциплины (не Settings-hub).

- Заголовок: **«Выберите спортивную дисциплину»**.
- Подзаголовок: **«Изменить спортивную дисциплину можно в настройках приложения»**.
- Плитки:
  - **Мотокросс** (без иконки редактирования) → выбор → прежний MX flow;
  - каждая **сохранённая** пользовательская дисциплина → тап = выбор и закрытие модалки;
  - на плитке пользовательской дисциплины — **иконка ✎** → открывает редактор этой дисциплины (не путать с выбором);
  - **«Добавить новую спортивную дисциплину»** → сразу `discipline-editor` (создание).
- Cold start: модалка, если дисциплина ещё не выбрана; если выбрана — сразу в работу. Смена — из Settings (та же модалка).

### B1. Settings → «Спортивная дисциплина»

- Заголовок блока: **«Спортивная дисциплина»** (не «Дисциплина»).
- Одна кнопка: название **текущей** дисциплины + подпись **«Изменить спортивную дисциплину»**.
- Нажатие → снова `work-mode-modal`.
- Отдельный пункт Settings «Дисциплины» / hub со списком — **не использовать** (чтобы не было двух мест выбора).

### B2. Редактор дисциплины (`discipline-editor`)

- Открывается из «Добавить новую…» или из ✎ на плитке.
- Поля: **название** спортивной дисциплины.
- Типы заездов MVP (предустановки): `mass_start_time`, `qualification_best` — добавить / переименовать / удалить внутри этого экрана.
- После **сохранения новой** дисциплины она появляется плиткой в `work-mode-modal`.
- Хранение: локально (SQLite / Preferences); ключ пользователя Вокруг — когда есть логин.

### B3. Логин Вокруг

- Экран/вкладка входа аккаунтом Вокруг (отдельно от МотоТрека).
- Ошибка, если нет доступа Чекпоинт.

### B4. Импорт соревнования

- Список с API (или файл офлайн-пакета).
- Подтверждение импорта → локальная копия события + участников.

### B5. Участники импортированного события

- Таблица: ФИО, номер, группа, RFID.
- Редактирование RFID.
- Предупреждение, если RFID пустой.

### B6. Создание заезда

- Выбор типа из шаблона дисциплины.
- Выбор участников (все / группа / вручную — минимум: все или фильтр по группе).
- Старт.

### B7. Хронометраж (один створ)

- Как привычный экран фиксации; правила — по выбранному типу.
- Сохранение меток и статуса finished в локальную БД без сети.

### B7a. Локальные итоги завершённого заезда (этап 2, E2-11)

- Из списка заездов у finished — открыть **Результаты**.
- Таблица мест / времён по типу заезда (офлайн).
- Опционально: локальный PDF/export (E2-11b), без блокировки флагом публикации.
- Не путать с эфиром в Вокруг.

### B8. Эфир и «поделиться» (этап 3, не этап 2)

- Отправка live/final в Вокруг по [06-results-contract-v1.md](./06-results-contract-v1.md).
- Сервер принимает только при праве публикации (флаг админки до оплаты; позже подписка).
- На карточке события — live и итоги; «поделиться» ссылкой на событие.
- Локальный просмотр итогов (B7a) работает **без** флага.

```text
Чекпоинт MVP (этап 2)
work-mode-modal: Мотокросс | сохранённые дисциплины | «Добавить новую…»
        |                              |
        |                              +--> discipline-editor (имя + типы)
        v
выбранная дисциплина
        |
[Логин Вокруг] --> [Импорт] --> [Метки] --> [Заезд] --> [Хронометраж] --> [Локальные итоги]

Settings: кнопка текущей дисциплины --> снова work-mode-modal
```

## C. Сквозной сценарий приёмки (до эфира)

1. Админ выдал доступ тестовому пользователю.
2. Пользователь создал событие, включил чекбокс, заполнил комиссию (Excel + одна ручная строка).
3. В Чекпоинте: модалка выбора → «Добавить новую…» / выбрать дисциплину → импорт → правка RFID → заезд → финиш → **открыть локальные итоги** из списка.
4. Смена дисциплины — только из Settings → та же модалка.
5. Мотокросс-путь по-прежнему открывается и не падает на дымовом сценарии.

Эфир на карточке Вокруг — сценарий этапа 3.
