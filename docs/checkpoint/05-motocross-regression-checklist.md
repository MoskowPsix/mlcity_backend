# Чеклист регрессии мотокросса (Чекпоинт)

Прогонять после задач, которые затрагивают общий UI, навигацию, антенну или SQLite (**минимум:** после E2-01 и после E2-08).  
Результат — в комментарии YouGile к E2-10 (дата, ветка/сборка).

## Обязательные пункты

| # | Шаг | OK? |
|---|---|---|
| 1 | Приложение открывается, нет белого экрана на старте | |
| 2 | Вход в поток **Мотокросс** (не «Своя дисциплина») | |
| 3 | Логин аккаунтом **МотоТрек** работает (токен сохраняется) | |
| 4 | Импорт гонки из МотоТрека (онлайн или привычный способ) | |
| 5 | Список участников гонки на месте | |
| 6 | Создание/открытие заезда (arrival) как раньше | |
| 7 | Экран старта заезда открывается | |
| 8 | Ручная отметка участника / пересечение отражается в live-таблице (если антенны нет — ручной тап) | |
| 9 | Завершение/сохранение результата не падает с ошибкой | |
| 10 | Повторный вход в Мотокросс после визита в «Свою дисциплину» | |
