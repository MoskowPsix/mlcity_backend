# Приёмка этапа 1 (сценарий S1)

Локально: приложение `http://127.0.0.1:8100`, API `http://127.0.0.1:8001`. На стенде те же пути. Образец бланка: [fixtures/participants-sample.csv](./fixtures/participants-sample.csv).

1. В админке `/moon` у тестового пользователя включить «Доступ Checkpoint» и «Публикация результатов Checkpoint».
2. Войти в приложение этим пользователем. Профиль → Checkpoint: доступ «есть», публикация «разрешена», в списке дата и ссылка в комиссию. Без флага тот же пункт меню открывает текст «Доступ выдаёт менеджер после комплекта» и не показывает чужие списки.
3. Создать мероприятие или открыть своё. Галка «Использовать хронометраж Чекпоинт» есть только с доступом. Включил и сохранил — у события она стоит, выключил и сохранил — снята. Кнопка «Комиссия» ведёт в `/cabinet/events/{id}/commission`.
4. В комиссии создать группу «М18», добавить участника в неё, второго в другую группу, поправить RFID, удалить одного. Чужой аккаунт эту комиссию не открывает.
5. «Скачать шаблон». В колонке «Группа» добавить новую группу «Ж18», загрузить файл. Заголовки бланка дают превью без сопоставления, затем «Загрузить». Повтор того же стартового номера обновляет участника. Два одинаковых номера в файле — ошибка со строкой, в базу не пишется ничего из этого файла.
6. Файл с заголовками «Фамилия / Имя / Номер / Группа»: кнопка импорта неактивна, пока не сопоставлены фамилия, имя и стартовый номер. После «Проверить колонки» — превью и импорт, группа из колонки создаётся сама.
7. Токен взять из входа (`POST /api/login`). `GET /api/checkpoint/competitions` — только свои события с галкой. `GET /api/checkpoint/competitions/{id}` и `GET /api/checkpoint/competitions/{id}/export` — `groups[]`, `participants[]` (пустые массивы, если пусто), `group_name`, `publish_allowed`. Другой пользователь с доступом чужое событие не видит: нет в списке, деталь 403/404.
8. В комиссии владельца пригласить известную почту — статус «принял», этот человек открывает группы и Excel, блок приглашений и чекбокс ему закрыты. Неизвестная почта — «не принял», доступа нет, пока нет регистрации с неё. «Удалить» убирает строку и доступ.
