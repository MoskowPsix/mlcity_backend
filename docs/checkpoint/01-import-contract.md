## 1. Цель

Чекпоинт (путь «своя дисциплина») забирает из Вокруг **готовое соревнование** (мероприятие с включённым хронометражем), **группы/классы** и **стартовый список** из комиссии. Мотокросс / МотоТрек в этот контракт не входят.

---

## 2. Авторизация и доступ

| Параметр | Значение |
|---|---|
| Кто логинится | Пользователь Вокруг с флагом **доступ Чекпоинт** |
| Логин | `POST /api/login` (как в mlcity_backend сейчас) → Bearer Sanctum |
| Base URL | Конфиг в Чекпоинте (dev/stage/prod), отдельно от `apiMotoTrackUrl` |
| Где хранить токен в Чекпоинте | Отдельно от токена МотоТрека |
| Без доступа Чекпоинт | API импорта → `403` |

**Кто видит соревнования в импорте:** только **автор** мероприятия (user_id события) с `checkpoint_access` и `checkpoint_enabled = true`. Чужие события → `403`/`404`.

Эндпоинты импорта: `auth:sanctum` + проверка `checkpoint_access`.

## 3. Эндпоинты (минимум для стыка)

Базовый префикс: `/api/checkpoint/…`

### 3.1. Список соревнований для импорта

`GET /api/checkpoint/competitions`

Пример элемента списка:

```json
{
  "id": 1001,
  "name": "Кубок города — лыжи",
  "date_start": "2026-12-01",
  "date_end": "2026-12-01",
  "city": "Казань",
  "participants_count": 42,
  "groups_count": 2,
  "publish_allowed": true,
  "updated_at": "2026-11-20T12:00:00+03:00"
}
```

### 3.2. Детали соревнования + группы + участники

`GET /api/checkpoint/competitions/{id}`

```json
{
  "competition": {
    "id": 1001,
    "name": "Кубок города — лыжи",
    "date_start": "2026-12-01",
    "date_end": "2026-12-01",
    "city": "Казань",
    "place_name": null,
    "checkpoint_enabled": true,
    "publish_allowed": true,
    "updated_at": "2026-11-20T12:00:00+03:00"
  },
  "groups": [
    { "id": 1, "name": "М18", "sort_order": 1 },
    { "id": 2, "name": "Ж18", "sort_order": 2 }
  ],
  "participants": [
    {
      "id": 55,
      "last_name": "Иванов",
      "first_name": "Иван",
      "middle_name": null,
      "birth_date": "1998-05-12",
      "city": "Казань",
      "group_id": 1,
      "group_name": "М18",
      "start_number": "12",
      "rfid": null,
      "updated_at": "2026-11-20T11:00:00+03:00"
    }
  ]
}
```

| Поле groups[] | Смысл |
|---|---|
| id | Стабильный id группы в рамках события |
| name | Название группы/класса |
| sort_order | Порядок в UI (целое, по умолчанию 0) |

У участника **group_id** может быть `null` (без группы); **group_name** дублируется для офлайн/отображения в Чекпоинте без lookup.

### 3.3. Офлайн-пакет

`GET /api/checkpoint/competitions/{id}/export`

Тот же JSON, что §3.2 (или обёртка `{ "version": 1, "exported_at": "...", ... }`).

## 4. Группы в комиссии (Вокруг)

- Группы хранятся **на уровне события** (отдельная таблица/сущность).
- В UI: список групп (создать / переименовать / удалить, если нет участников в группе).
- Участник: выбор группы из списка или «без группы».
- При **ручном** создании участника — только существующие группы или создание группы заранее.

### 4.1. Excel и группы

**Рекомендуемый путь:** организатор скачивает **бланк Excel** из комиссии (фиксированные заголовки + 1–2 примера строк), заполняет и загружает.

Колонки бланка (первая строка — заголовки):

`last_name`, `first_name`, `middle_name`, `birth_date`, `city`, `group_name`, `start_number`, `rfid`

Правила при импорте из Excel:

1. Если заголовки **совпали** с бланком — маппинг не показываем, сразу **превью** → подтверждение.
2. Если заголовки **другие** — экран **сопоставления колонок** (колонка файла → поле бланка) → превью → импорт.
3. Непустое **group_name** в строке: если группы с таким именем нет — **создать**; участник получает `group_id`.
4. Пустое **group_name** — участник без группы.
5. **start_number** уникален в рамках одного события; дубликат → ошибка с указанием строк.

Отдельный лист «только группы» в Excel **не используем** в v1.1.

## 6. Повторный импорт и синхронизация (пилот)

- В Вокруг: изменения комиссии обновляют `updated_at` события/участников.
- Чекпоинт при повторном импорте: **upsert** участников по `participants[].id`.
- Участники, **исчезнувшие** из ответа API, в Чекпоинте **не удаляются автоматически** (чтобы не сорвать уже начатый заезд); удаление локально — отдельное действие судьи (этап 2, UX уточняется).

## 7. Ошибки

| Код | Когда |
|---|---|
| 401 | Нет / просрочен токен |
| 403 | Нет доступа Чекпоинт или не автор события |
| 404 | Нет события или `checkpoint_enabled = false` |
| 422 | Валидация (дубликат номера при Excel и т.д.) |

Пустой `participants: []` допускается; пустой `groups: []` допускается.
